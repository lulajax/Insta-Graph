### **项目介绍：Insta-Graph 社群分析器**

**1. 项目简介**

`Insta-Graph` 是一个专为社交媒体分析师设计的图数据库应用。它旨在解决从海量 Instagram 用户中高效发现特定领域或社群核心成员的挑战。

与依赖大规模数据抓取的传统方法不同，本系统采用一种“小而精”的策略：分析师仅需提供一小批已知的“种子博主”，系统即可通过分析他们之间深度的关联关系（尤其是在同一帖子中被共同标记），智能地推荐出与该群体高度相关的新博主。

该工具的核心价值在于关系挖掘的深度而非数据量的广度，使分析师能像侦探一样，从微小的线索出发，逐步绘制出整个社群的精准网络图谱。

**2. 核心设计目标**

*   **高效性 (Efficiency):** 避免进行大规模、无差别的数据采集。通过聚焦一小群“种子用户”及其强关联数据，以最经济的方式获得最高价值的发现。

*   **精准性 (Precision):** 系统的分析核心是“共同被标记” (`:CO_TAGGED`) 关系。这种关系被视为现实世界中强关联的有效证明（如共同参加活动、合作等），从而确保推荐出的新博主与目标社群有极高的相关性。

*   **迭代式发现 (Iterative Discovery):** 系统的工作流被设计为一个持续的“分析-发现-拓展”循环。新发现的博主可以被“晋升”为新的种子，用于下一轮的探索，从而实现社群网络的滚动式、有机增长。

*   **项目制管理 (Project-Based Management):** 支持通过 `seed_group` 属性对不同的分析项目（例如“釜山舞者社群”、“首尔美食家圈子”）进行隔离和管理，确保数据和分析的条理性。

**3. 技术实现方式**

*   **核心存储与查询：**
    *   **图数据库 (Neo4j v5.x):** 采用业界领先的图数据库 Neo4j 存储博主 (`:Blogger`)、帖子 (`:Post`) 等实体节点，以及他们之间的关注 (`:FOLLOWS`) 和标记 (`:TAGGED_IN`) 等关系。
    *   **Cypher 查询语言:** 所有的分析逻辑均通过强大且直观的 Cypher 语言实现，能够高效地执行复杂的多跳关系查询。

*   **后端服务：**
    *   **API (Spring Boot / Java 21):** 后端采用稳定且高效的 Spring Boot 框架构建，对外提供 RESTful API 接口。这些接口负责接收分析师的数据录入请求和分析查询请求，并将其转换为底层的 Cypher 查询。

*   **前端界面 (可选):**
    *   **数据录入 UI (Vue.js):** 为了提升人工录入的体验，系统设计了一个可选的前端界面。推荐使用 Vue.js 框架构建，为分析师提供一个友好的 Web 表单来提交数据。分析师也可以直接通过 Swagger UI 等工具与后端 API 交互。

*   **部署与运维：**
    *   **容器化 (Docker / Docker Compose):** 整个应用（Neo4j 数据库、Spring Boot 后端、Vue 前端）被完整地容器化，通过 Docker Compose 进行编排，实现一键式部署和跨平台环境一致性，极大地简化了运维成本。
